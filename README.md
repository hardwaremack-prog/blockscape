# Blockscape

A ray-traced voxel survival world that runs in a single HTML file.

![Blockscape screenshot](<Blockscape - screenshot.png>)

## What you can do

- Break and place blocks in a ray-traced 3D world with real lighting and see-through glass
- Chop wood, build a crafting table, then craft an axe, fishing rod, hoe, doors, roofing, pressure plates and windows
- Hunt pigs, cows and chickens for meat and keep your hunger up; staying fed slowly heals you
- Feed a fireplace with wood or scrap to keep warm
- Build an enclosed shelter with a door before night, when creepers come out
- Save your world with **K**

## Controls

| Key | Action |
|---|---|
| WASD / Space / Shift | Walk, jump, sprint |
| Mouse | Look around |
| Left click (hold) | Break a block or attack |
| Right click | Place a block from your inventory |
| 0–9 or scroll wheel | Pick a block or tool |
| C | Crafting |
| E | Open or close a nearby door |
| F | Eat meat |
| M | Mute |
| K | Save |
| Esc | Release the mouse |

## Run it

Download `blockscape.html` and open it in your web browser. No install, no account, nothing to set up.
